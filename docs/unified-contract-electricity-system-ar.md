# تصور نظام إدارة مشروع العقد الموحد لشركة كهرباء في السعودية

## 1. الهدف العام
يهدف النظام إلى توفير منصة مركزية لإدارة ومتابعة أعمال مشروع العقد الموحد، بحيث يستطيع مدير المشروع مراقبة طلبات أوامر العمل والمشاريع عبر قسم الأرشيف، ويتمكن مهندس الكهرباء من الوصول إلى الأرشيف والمكتب الفني وعرض المخططات الكهربائية المرفوعة حسب الصلاحيات المعتمدة.

## 2. المستخدمون والصلاحيات

### 2.1 مدير المشروع
- الاطلاع على لوحة تحكم شاملة لمؤشرات الأداء وحالة أوامر العمل والمشاريع.
- الدخول إلى قسم الأرشيف لمتابعة جميع الطلبات والمشاريع المدخلة.
- البحث والتصفية حسب رقم أمر العمل، المشروع، المنطقة، الحالة، التاريخ، ومدخل البيانات.
- مراجعة سجل التحديثات والمرفقات والاعتمادات المرتبطة بكل طلب.
- تصدير التقارير الدورية بصيغ مناسبة مثل PDF وExcel.

### 2.2 مدخل البيانات
- إنشاء طلبات أوامر العمل وإدخال بيانات المشاريع الأساسية.
- رفع المستندات المطلوبة مثل الخطابات، النماذج، الصور، ومحاضر الاستلام.
- تحديث حالة الطلب ضمن المراحل المسموحة له فقط.
- تصحيح البيانات قبل اعتمادها أو أرشفتها.

### 2.3 مهندس الكهرباء
- الدخول إلى قسم الأرشيف للاطلاع على أوامر العمل والمشاريع ذات العلاقة.
- الدخول إلى قسم المكتب الفني لمراجعة البيانات الفنية.
- عرض المخططات الكهربائية المرفوعة وتنزيلها عند الحاجة.
- إضافة ملاحظات فنية على الطلب أو المخطط دون تعديل البيانات الإدارية غير المصرح بها.

### 2.4 مسؤول النظام
- إدارة المستخدمين والأدوار والصلاحيات.
- ضبط القوائم المرجعية مثل المناطق، أنواع الأعمال، حالات الطلب، وأنواع المرفقات.
- متابعة سجلات الدخول والتعديلات لضمان الحوكمة والأمان.

## 3. الأقسام الرئيسية للنظام

### 3.1 لوحة التحكم
- تعرض عدد أوامر العمل حسب الحالة: جديد، قيد المراجعة، معتمد، مرفوض، مكتمل، ومؤرشف.
- تعرض المشاريع المفتوحة والمتأخرة والمنجزة.
- تعرض تنبيهات للطلبات التي لم يتم تحديثها خلال مدة محددة.
- توفر مؤشرات أداء لمدخلين البيانات والمكتب الفني.

### 3.2 قسم الأرشيف
- يمثل المستودع المركزي لجميع طلبات أوامر العمل والمشاريع.
- يحتوي على صفحة تفاصيل لكل طلب تشمل البيانات الأساسية، الحالة، المرفقات، سجل الإجراءات، والملاحظات.
- يدعم البحث المتقدم والتصفية والحفظ كقوائم مخصصة.
- يمنع حذف السجلات المعتمدة، مع السماح بالأرشفة أو إلغاء الأرشفة حسب الصلاحية.

### 3.3 قسم المكتب الفني
- يختص بمراجعة البيانات الفنية والمخططات الكهربائية.
- يسمح برفع المخططات الكهربائية وربطها بأمر عمل أو مشروع محدد.
- يدعم إصدارات متعددة للمخطط مع حفظ تاريخ كل إصدار واسم الرافع.
- يتيح لمهندس الكهرباء إضافة ملاحظات واعتمادات فنية.

### 3.4 إدارة أوامر العمل
- إنشاء أمر عمل جديد برقم مرجعي فريد.
- ربط أمر العمل بالمشروع والمنطقة ونوع العمل والمقاول أو الفريق المسؤول.
- تتبع دورة حياة أمر العمل من الإدخال حتى الإغلاق والأرشفة.
- حفظ جميع المرفقات والمراسلات المرتبطة بالأمر.

### 3.5 إدارة المشاريع
- تسجيل بيانات المشروع الأساسية مثل الاسم، الموقع، النطاق، تاريخ البداية، وتاريخ النهاية المتوقع.
- ربط المشروع بعدة أوامر عمل ومخططات ومستندات.
- متابعة نسب الإنجاز والملاحظات والعوائق.
- عرض ملخص تنفيذي للمشروع لمدير المشروع.

## 4. دورة العمل المقترحة
1. يقوم مدخل البيانات بإنشاء طلب أمر عمل أو مشروع جديد وإدخال البيانات الأساسية.
2. يرفع مدخل البيانات المستندات الأولية والمرفقات المطلوبة.
3. ينتقل الطلب إلى الأرشيف بحالة "جديد" أو "قيد المراجعة" حسب الإعدادات.
4. يراجع مدير المشروع الطلب من قسم الأرشيف ويتابع اكتمال البيانات.
5. عند وجود مخططات أو بيانات فنية، يتم تحويل الطلب إلى قسم المكتب الفني.
6. يراجع مهندس الكهرباء المخططات الكهربائية ويضيف ملاحظاته أو اعتماده الفني.
7. يتم تحديث حالة الطلب بناء على نتيجة المراجعة الفنية والإدارية.
8. بعد اكتمال الإجراءات، يتم إغلاق الطلب وأرشفته مع الاحتفاظ بسجل كامل للتغييرات.

## 5. البيانات الأساسية المطلوبة

### 5.1 بيانات أمر العمل
- رقم أمر العمل.
- تاريخ الإنشاء.
- المنطقة أو المدينة.
- نوع العمل.
- وصف العمل المطلوب.
- الجهة أو الفريق المسؤول.
- الحالة الحالية.
- الأولوية.
- مدخل البيانات.

### 5.2 بيانات المشروع
- رقم المشروع.
- اسم المشروع.
- الموقع.
- نطاق العمل.
- تاريخ البداية.
- تاريخ النهاية المتوقع.
- نسبة الإنجاز.
- مدير المشروع المسؤول.

### 5.3 بيانات المخططات الكهربائية
- رقم المخطط أو كوده.
- اسم المخطط.
- نوع المخطط.
- رقم الإصدار.
- تاريخ الرفع.
- اسم الرافع.
- الملف المرفوع.
- ملاحظات مهندس الكهرباء.

## 6. المتطلبات غير الوظيفية
- واجهة عربية واضحة مع دعم الاتجاه من اليمين إلى اليسار.
- نظام صلاحيات قائم على الأدوار لضمان عدم وصول المستخدم إلا للأقسام المصرح بها.
- سجل تدقيق يحفظ كل عملية إضافة أو تعديل أو اعتماد أو أرشفة.
- نسخ احتياطي دوري للبيانات والمرفقات.
- إمكانية التوسع لاحقا لإضافة تطبيق جوال أو تكامل مع أنظمة خارجية.
- تشفير الاتصال وحماية الملفات المرفوعة من الوصول غير المصرح.

## 7. تقارير مقترحة
- تقرير أوامر العمل حسب الحالة والفترة الزمنية.
- تقرير المشاريع حسب المنطقة ونسبة الإنجاز.
- تقرير المخططات الكهربائية المرفوعة والمعتمدة والمرفوضة.
- تقرير إنتاجية مدخلين البيانات.
- تقرير الطلبات المتأخرة أو التي تحتاج إجراء.

## 8. نموذج قائمة أولويات التنفيذ
1. إدارة المستخدمين والصلاحيات.
2. إنشاء أوامر العمل والمشاريع.
3. قسم الأرشيف والبحث المتقدم.
4. رفع المرفقات والمخططات الكهربائية.
5. قسم المكتب الفني وملاحظات مهندس الكهرباء.
6. لوحة التحكم والتقارير.
7. سجل التدقيق والتنبيهات.
